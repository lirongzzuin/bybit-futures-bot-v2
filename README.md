### v7.6 핵심 개선 — 대형 손실 제거 + 시간 기반 관리

v7.5 28건 추가 분석: WR 53.6%로 개선됐으나, 5건의 대형 손실($1.2~1.6)이 전체 수익 잠식

| 문제 | 데이터 | 근본 원인 | 해결 |
|------|--------|----------|------|
| 대형 손실 5건 = -$6.65 | 전체 손실의 93% | 포지션 크기 + 긴급청산 느슨 | **긴급청산 -5%, 리스크 축소** |
| 노셔널 $100+ = 33% WR | vs <$30 = 100% WR | 큰 포지션이 손실 주범 | **마진비율 20%, 비중조절 제거** |
| 1-2시간 보유 = 36% WR | vs <60분 = 64% WR | 장기 보유 → 손실 확대 | **90분 타임아웃 청산** |
| TP 이동이 역효과 | 모든 조정이 "weak_signal" | TP 이동 = 체결률 하락 | **TP 고정, SL만 타이트닝** |
| 강도별 2x 비중 → 큰 손실 | 강도 무의미 확인 | 비중 증가 = 손실 증가 | **균일 비중 (1.0x)** |

## 전략: 시장 레짐 자동 감지

4H ADX로 시장 상태를 분류하고, 각 상태에 최적화된 전략 자동 적용:

```
ADX >= 25 → 추세장 → 추세추종 (Trend-Following)
ADX 20-25 → 전환기 → 보수적 평균회귀
ADX < 20  → 횡보장 → 평균회귀 (Mean-Reversion)
```

### 추세추종 모드 (ADX >= 25)
| 항목 | 설정 |
|------|------|
| 방향 | 4H **+DI > -DI** = 롱, 반대 = 숏 |
| 진입 | 15min EMA9/21 정배열 + MACD 확인 + RSI 40-70 |
| TP/SL | **2.0x / 1.5x ATR** (R:R 1.33:1) |
| 레버리지 | **15x** |

### 평균회귀 모드 (ADX < 20)
| 항목 | 설정 |
|------|------|
| 방향 | RSI < 30 = 롱, RSI > 70 = 숏 |
| 진입 | 15min RSI 극단 + BB 밴드 터치 + RSI 반전 |
| TP/SL | **1.2x / 0.8x ATR** (R:R 1.5:1) |
| 레버리지 | **15x** |

### 전환 모드 (ADX 20-25)
| 항목 | 설정 |
|------|------|
| 방향 | 4H EMA 추세 + 15min 평균회귀 |
| TP/SL | 1.4x / 1.2x ATR |
| 레버리지 | 15x |
| 특징 | 엄격한 필터 (min_score 2.5) |

## 포지션 동적 관리 — v7.6 리스크 최적화

```
손실 -5%  → 긴급 청산 (v7.6: was -8%)
90분 보유 + 손실 → 타임아웃 청산 (v7.6 신규)
60분 보유 + 본전 → 본전 SL 강제 (v7.6 신규)
수익 1%+  → SL을 본전으로 이동 (수수료 반영)
수익 1.5%+ → 트레일링 SL 시작 (수익의 40% 보호)
수익 2%+  → 트레일링 강화 (수익의 50% 보호)
수익 3%+  → 트레일링 강화 (수익의 60% 보호)
수익 5%+  → 트레일링 강화 (수익의 75% 보호)
TP 60%   → 1차 부분 익절 (30% 청산)
TP 80%   → TP 자동 확대 (+50%) ← 무한 반복
수익 10%+ → 트레일링 최대 (수익의 85% 보호)
TP 200%  → 2차 부분 익절 (추가 30% 청산)
```

### 동적 SL 관리 (v7.6 — TP 이동 제거)
| 상황 | 행동 | 이유 |
|------|------|------|
| 수익 중 + 약한 시그널 | SL → 수익의 70% 보호 | 수익 확보 |
| 수익 중 + 강한 시그널 | SL → 수익의 50% 보호 | 여유 있게 보호 |
| TP | **진입 시 설정 그대로 유지** | 데이터: TP 이동 → 체결률 하락 |
### 시그널 필터
- **최소 진입 강도: 0.65** (실거래 데이터: 강도와 승률 무상관 — 노이즈 필터용)
- **동일 심볼 재진입 쿨다운: 30분** (연속 손절 방지)
- 반대 시그널: **강도 0.65+** 만 청산 (약한 시그널 무시)
- RSI 반전: 수익 **3%+** AND RSI **78+/22-** AND 3봉 연속 꺾임

### 일봉 전환 보호 (KST 08:45~09:15)
- 신규 진입 차단
- 수익 중 포지션: SL을 수익의 70% 보호
- 본전 근처: 본전 SL 강제
- 손실 중: SL을 -4%로 타이트닝
