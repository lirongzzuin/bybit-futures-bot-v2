## 전략: 시장 레짐 자동 감지

4H ADX(Average Directional Index)로 시장 상태를 분류하고, 각 상태에 최적화된 전략 자동 적용:

```
ADX >= 25 → 추세장 → 추세추종 (Trend-Following)
                      큰 움직임을 타고 가서 크게 수익!

ADX 20-25 → 전환기 → 보수적 평균회귀
                      엄격한 필터로 안전하게

ADX < 20  → 횡보장 → 평균회귀 (Mean-Reversion)
                      RSI 극단에서 빠르게 스캘핑!
```

### 추세추종 모드 (ADX >= 25)
| 항목 | 설정 |
|------|------|
| 방향 | 4H **+DI > -DI** = 롱, 반대 = 숏 |
| 진입 | 15min EMA9/21 정배열 + MACD 확인 + RSI 40-70 |
| TP/SL | **4.0x / 2.0x ATR** (R:R 2:1) |
| 레버리지 | **20x** |
| 특징 | 넓은 TP로 큰 추세를 끝까지 타고 감 |

### 평균회귀 모드 (ADX < 20)
| 항목 | 설정 |
|------|------|
| 방향 | RSI < 30 = 롱, RSI > 70 = 숏 (**4H 무관**) |
| 진입 | 15min RSI 극단 + BB 밴드 터치 + RSI 반전 |
| TP/SL | **1.5x / 1.0x ATR** (R:R 1.5:1) |
| 레버리지 | **30x** |
| 특징 | 타이트 SL로 높은 레버리지, 빠른 스캘핑 |

### 전환 모드 (ADX 20-25)
| 항목 | 설정 |
|------|------|
| 방향 | 4H EMA 추세 + 15min 평균회귀 |
| TP/SL | 2.0x / 1.5x ATR |
| 레버리지 | 20x |
| 특징 | 엄격한 필터 (min_score 2.5) |

## 포지션 동적 관리 — 수익 극대화 시스템

포지션 진입 후 **1분마다** 실시간 모니터링하며, 수익 단계에 따라 SL/TP를 자동 조정합니다:

```
수익 1%+  → SL을 본전으로 이동 (손실 제로 보장)
수익 2%+  → 트레일링 SL 시작 (수익의 35% 보호)
수익 3%+  → 트레일링 강화 (수익의 50% 보호)
TP 50%   → 1차 부분 익절 (30% 청산, 70% 계속 홀딩)
수익 5%+  → 트레일링 강화 (수익의 65% 보호)
TP 80%   → TP 자동 확대 (+50%) ← 무한 반복!
수익 10%+ → 트레일링 최대 (수익의 80% 보호)
TP 200%  → 2차 부분 익절 (추가 30% 청산)
TP 다시 80% → 또 확대... 추세가 끝날 때까지!
```

**핵심**: TP는 무한 확대되고, 추세가 끝나면 트레일링 SL에 걸려서 수익 대부분 보존.
작은 수익은 빨리 확정, 큰 수익은 끝까지 타고 감!

### 모멘텀 소진 감지 (시장가 즉시 청산)
- 수익 중 RSI > 80 (롱) → 상승 여력 소진, 시장가 익절
- 수익 중 RSI < 20 (숏) → 하락 여력 소진, 시장가 익절
- ATR이 평균의 60% 미만으로 수축 → 추세 종료, SL 85%로 타이트닝

### 다단계 피라미딩 (최대 3회 추가 진입)
| 횟수 | 추가 수량 | 필요 시그널 강도 | 조건 |
|------|----------|----------------|------|
| 1차 | 원래의 50% | 강도 >= 0.6 | 수익 중 + 같은 방향 |
| 2차 | 원래의 30% | 강도 >= 0.7 | 수익 중 + 같은 방향 |
| 3차 | 원래의 20% | 강도 >= 0.8 | 수익 중 + 같은 방향 |

## 잔고 적응형 리스크 관리

잔고 규모에 따라 실질 리스크를 자동 조정 (레버리지 역산):

| 잔고 | 실질 리스크/거래 | 특성 |
|------|----------------|------|
| < $500 | **12%** | 소액 공격적 성장 |
| < $2,000 | **8%** | 성장기 |
| < $10,000 | **6%** | 표준 |
| $10,000+ | **4%** | 대액 안정화 |

레버리지와 무관하게 실질 리스크가 일정하게 유지됩니다.
잔고가 커지면 자동으로 보수적으로, 작으면 공격적으로 전환.

```
$103 잔고 → 실질 12% → 6개월 평균 +4,041% 복리 성장
$10,000 잔고 → 실질 4% → 안정적 복리 성장
```
