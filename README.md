## 전략: 시장 레짐 자동 감지

4H ADX로 시장 상태를 분류하고, 각 상태에 최적화된 전략 자동 적용:

```
ADX >= 25 → 추세장 → 추세추종 (Trend-Following)
ADX 20-25 → 전환기 → 보수적 평균회귀
ADX < 20  → 횡보장 → 평균회귀 (Mean-Reversion)
```

### 추세추종 모드 (ADX >= 25)
| 항목 | 설정 |
|------|------|
| 방향 | 4H **+DI > -DI** = 롱, 반대 = 숏 |
| 진입 | 15min EMA9/21 정배열 + MACD 확인 + RSI 40-70 |
| TP/SL | **2.0x / 1.5x ATR** (R:R 1.33:1) |
| 레버리지 | **15x** |

### 평균회귀 모드 (ADX < 20)
| 항목 | 설정 |
|------|------|
| 방향 | RSI < 30 = 롱, RSI > 70 = 숏 |
| 진입 | 15min RSI 극단 + BB 밴드 터치 + RSI 반전 |
| TP/SL | **1.2x / 0.8x ATR** (R:R 1.5:1) |
| 레버리지 | **15x** |

### 전환 모드 (ADX 20-25)
| 항목 | 설정 |
|------|------|
| 방향 | 4H EMA 추세 + 15min 평균회귀 |
| TP/SL | 1.4x / 1.2x ATR |
| 레버리지 | 15x |
| 특징 | 엄격한 필터 (min_score 2.5) |

## 포지션 동적 관리 — v7.5 수익 극대화 시스템

```
수익 1%+  → SL을 본전으로 이동 (손실 제로 보장)
수익 1.5%+ → 트레일링 SL 시작 (수익의 40% 보호)
수익 2%+  → 트레일링 강화 (수익의 50% 보호)
수익 3%+  → 트레일링 강화 (수익의 60% 보호)
TP 30%   → 조기 부분 익절 (25% 청산) ← v7.4 신규
수익 5%+  → 트레일링 강화 (수익의 75% 보호)
TP 60%   → 1차 부분 익절 (30% 청산)
TP 80%   → TP 자동 확대 (+50%) ← 무한 반복!
수익 10%+ → 트레일링 최대 (수익의 85% 보호)
TP 200%  → 2차 부분 익절 (추가 30% 청산)
```

### 시그널 강도 기반 실시간 TP/SL 조정 (v7.5)

| 0.9+ | 2.5x | 1.8x | 수익 기회 확대 |
| 0.8+ | 2.2x | 1.5x | 수익 확대 |

### 시그널 필터
- **최소 진입 강도: 0.65** (실거래 데이터: 강도와 승률 무상관 — 노이즈 필터용)
- **동일 심볼 재진입 쿨다운: 30분** (연속 손절 방지)
- 반대 시그널: **강도 0.65+** 만 청산 (약한 시그널 무시)
- RSI 반전: 수익 **3%+** AND RSI **78+/22-** AND 3봉 연속 꺾임

### 일봉 전환 보호 (KST 08:45~09:15)
- 신규 진입 차단
- 수익 중 포지션: SL을 수익의 70% 보호
- 본전 근처: 본전 SL 강제
- 손실 중: SL을 -4%로 타이트닝
