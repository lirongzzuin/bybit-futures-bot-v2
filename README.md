## 현재 상태: 실전 운용 (v10.2)

실전 데이터 기반 생존 최적화 — v10.1 운용 중 7연패/MDD 50% 문제를 분석하여 근본적 해결.

### v10.2 변경사항 (2026-04-03) — 생존 최적화 + 데이터 수집 복구

**문제 분석 (v10.1 실전):**
- SL 1.2x ATR에서도 연속 스톱아웃 발생 (7연패)
- MDD 25.7% → circuit breaker 발동 → 봇 정지, 회복 불가
- 약한 추세(ADX 25~28)에서 진입 → 풀백이 아닌 추세 반전으로 손실
- 동시 2포지션 → 상관 손실 증폭 (같은 방향 2개 동시 손실)
- collector.db 0바이트 → 데이터 수집이 실제로 작동하지 않음

### v10.2 설계 철학

```
v10.0: "많이 잡자" → 넓은 필터, 높은 레버리지 → MDD 폭발
v10.1: "안전하게" → 필터 강화, 레버리지 축소 → 여전히 7연패
v10.2: "살아남자" → 극소수 최고 품질만, 최소 리스크 → 생존 → 복리 성장
```

핵심: **거래 빈도를 줄이고 승률을 높여서, 적은 거래로 복리 성장**

## 전략: Pullback-in-Trend v10.2

### 진입 조건 (6단계 필터)

```
1. 4H ADX >= 28          → 강한 트렌드만 진입 (v10.2: 28로 상향)
2. 4H 2봉 연속 추세       → 추세 안정성 검증 (v10.2 신규)
3. 4H +DI/-DI 방향       → 트렌드 방향 결정
4. 4H EMA9 > EMA21       → 트렌드 정렬 확인
5. 15m RSI 풀백           → 과매도/과매수 확인
   - 롱: RSI 25-38 (v10.2: 더 깊은 풀백만)
   - 숏: RSI 62-75 (v10.2: 더 깊은 풀백만)
6. 15m BB 밴드 터치       → 극단값 확인
   - 롱: 가격 <= BB 하단 + 0.15 ATR
   - 숏: 가격 >= BB 상단 - 0.15 ATR
```

### 시그널 스코어링 (최소 3.0점)

| 조건 | 점수 | 설명 |
|------|------|------|
| RSI 풀백 존 진입 | +1.5 | 기본 점수 |
| EMA21 근접 | +1.0 | 지지/저항 확인 |
| MACD 히스토그램 반전 | +0.5 | 모멘텀 전환 |
| RSI 방향 반전 | +0.5 | 바운스 확인 |
| 거래량 스파이크 (2.5x MA) | +0.3 | 거래량 확인 |

### TP/SL 설정 (v10.2: 변동성 적응)

| 변동성 레짐 | TP | SL | R:R |
|-------------|-----|-----|------|
| Extreme (ATR > 2.0x avg) | **3.0x ATR** | **2.0x ATR** | 1.50:1 |
| High (ATR > 1.3x avg) | **2.7x ATR** | **1.7x ATR** | 1.59:1 |
| Normal | **2.5x ATR** | **1.5x ATR** | 1.67:1 |
| Low (ATR < 0.7x avg) | **2.0x ATR** | **1.2x ATR** | 1.67:1 |

ADX 보너스: ADX >= 45 → TP +0.2x, ADX >= 55 → TP +0.3x

| 항목 | 값 |
|------|-----|
| 레버리지 | **5x** (v10.2: 연패 생존) |

| 최대 동시 포지션 | **1개** (집중 전략) |

## 포지션 동적 관리

```
손실 -5%   → 긴급 청산
120분 보유 + 손실 1%+ → 타임아웃 청산
60분 보유 + 본전 근처 → 본전 SL 강제
수익 0.8%+ → SL을 본전으로 이동 (수수료 반영)
수익 1.5%+ → 트레일링 SL 시작 (수익의 40%±5% 보호) ← 변동성 적응
수익 2%+   → 트레일링 강화 (수익의 50%±5% 보호)
수익 3%+   → 트레일링 강화 (수익의 60%±5% 보호)
수익 5%+   → 트레일링 강화 (수익의 75%±5% 보호)
수익 10%+  → 트레일링 최대 (수익의 85%±5% 보호)
  ※ 고변동성: -5%p (여유, whipsaw 방지) / 저변동성: +5%p (타이트, 수익확보)
TP 60%     → 1차 부분 익절 (30% 청산)
TP 80%     → TP 자동 확대 (+50%) ← 무한 반복
TP 200%    → 2차 부분 익절 (추가 30% 청산)
```

## 데이터 수집 시스템 (v10.2 복구)

별도 DB(`collector.db`)에 전략 개선용 데이터를 자동 축적합니다.
v10.2: 0바이트 DB 자동 감지 및 재생성, 견고한 초기화.

| 데이터 | 수집 주기 | 용도 |
|--------|-----------|------|
| **시장 스냅샷** | 15분 (캔들마다) | 전체 지표 상태 기록 — 패턴 분석, ML 학습 데이터 |
| **시그널 저널** | 시그널 발생 시 | 진입/스킵 모든 시그널 + 후속 가격 추적 — 필터 최적화 |
| **레짐 전환** | 변동 감지 시 | 변동성·트렌드 전환 이력 — 레짐 적응형 전략 개발 |
| **드로우다운 이벤트** | 진입 시 | 드로우다운 구간 기록 — 리스크 모델 검증 |
| **캔들 아카이브** | 15분 (최근 3개) | 15분봉 원시 데이터 장기 보관 — 향후 백테스트 |
| **상관관계** | 6시간 | 심볼 간 상관계수 — 포트폴리오 리스크 분석 |
| **성과 벤치마크** | 일별 | 전략 vs BTC/ETH 수익률 비교 — 알파 추적 |

### 스킵 시그널 가상 성과 추적

스킵된 시그널의 15분/30분/1시간/4시간 후 가격을 추적하여 "진입했다면 얼마를 벌었을까?"를 정량화합니다. 이 데이터로 필터 임계값을 최적화할 수 있습니다.
