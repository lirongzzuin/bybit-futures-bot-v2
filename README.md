# Crypto Futures Bot v16.0 — 5m + 1H Momentum Scalper

> Bybit USDT Perpetual Futures 자동매매 봇
> 5분봉 진입 + 1시간봉 추세 확인 + 동적 TP/SL 관리

## 매매 기준

### 1단계: 추세 확인 (1시간봉)
- **ADX >= 25**: 추세 강도 확인 (약한 추세 필터링)
- **+DI > -DI + EMA9 > EMA21**: 상승 추세 → 롱 진입 가능
- **-DI > +DI + EMA9 < EMA21**: 하락 추세 → 숏 진입 가능
- 롱/숏 모두 진입 가능 (선물거래 특성 활용)

### 2단계: 진입 타이밍 (5분봉)
- **RSI 풀백**: 롱 25-40 / 숏 60-75 (과매도/과매수 구간)
- **BB 밴드 근접**: 가격이 볼린저 밴드 하단(롱)/상단(숏) 근처
- **MACD 반전**: 히스토그램 2봉 연속 개선 시 +0.7점, 1봉 +0.4점
- **RSI 방향 반전**: 이전 봉 대비 RSI 반등 시 +0.5점
- **캔들 패턴**: 해머/상승장악 등 패턴 감지 시 +0.7점
- **거래량 스파이크**: 평균 대비 1.5x 이상 시 +0.3~0.8점
- **최소 스코어 2.5점** 이상만 진입

### 3단계: TP/SL 설정
- **TP**: 2.0x ATR (변동성 적응: 1.8~2.5x)
- **SL**: 1.2x ATR (변동성 적응: 0.8~1.5x)
- **R:R 비율**: 최소 1.67:1
- **최소 거리 보장**: TP 1.5%, SL 1.0% (ATR 작을 때 노이즈 방지)
- ADX >= 35 시 TP 보너스 +0.3x, ADX >= 45 시 +0.5x

### 4단계: 주문 실행
- **시그널 강도 >= 0.7**: 시장가 진입 (taker 0.055%)
- **시그널 강도 < 0.7**: 지정가 진입 (maker 0.02%)
- 지정가 미체결 시 2분 후 자동 취소

### 5단계: 보유 중 동적 관리 (2초마다 모니터링)

| 조건 | 동작 | 목적 |
|------|------|------|
| TP/SL 없음 | 자동 설정 (TP +3%, SL -5%) | 동기화 포지션 보호 |
| 수익 0.8%+ | SL → 본전 이동 (수수료 반영) | 손실 전환 방지 |
| 수익 1.5%+ | 트레일링 SL (수익의 40% 보호) | 수익 잠금 |
| 수익 2%+ | 트레일링 SL (수익의 50% 보호) | 수익 확대 |
| 수익 3%+ | 트레일링 SL (수익의 60% 보호) | 수익 보호 강화 |
| 수익 5%+ | 트레일링 SL (수익의 75% 보호) | 대부분 잠금 |
| 수익 10%+ | 트레일링 SL (수익의 85% 보호) | 거의 전부 잠금 |
| TP 60% 도달 | 30% 부분 익절 | 수익 일부 확정 |
| TP 80% 도달 | TP 자동 확대 (+50%) | 추가 상승 여유 |
| TP 200% 도달 | 추가 30% 부분 익절 | 대박 수익 확정 |
| 손실 -5% | 긴급 청산 | 대형 손실 방지 |
| 3시간 보유 + 손실 | 시간 초과 청산 | 횡보 손절 |

트레일링 SL은 변동성 레짐에 따라 자동 조절:
- 고변동성: -5%p (여유, whipsaw 방지)
- 저변동성: +5%p (타이트, 수익 확보)

### 6단계: 리스크 관리

| 항목 | 값 |
|------|-----|
| 거래당 리스크 | 3% |
| 동시 포지션 | 최대 3개 |
| 레버리지 | 5~12x (동적) |
| 일일 최대 손실 | 8% → 당일 매매 중단 |
| 재진입 쿨다운 | 15분 (동일 심볼) |
| 수수료 | Maker 0.02% / Taker 0.055% (PnL에서 차감) |

### 동적 레버리지

| 시그널 스코어 | 레버리지 |
|--------------|---------|
| < 2.5 | 5x |
| 2.5 ~ 3.0 | 7x |
| 3.0+ | 10~12x |

## v16.0 변경사항 (실전 데이터 기반)

실전 운용 중 급등락으로 손실 발생 → 데이터 분석 후 개선:

| 문제 | 원인 | 해결 |
|------|------|------|
| 급락 시 동시 손절 | 5포지션 같은 방향 | 3포지션으로 축소 |
| 레버리지 과다 | 10x → SL 히트 시 -10% | 7x로 축소 (-8.4%) |
| 약한 추세 진입 | ADX 20 | ADX 25로 상향 |
| 노이즈 SL | SL 1.0x ATR | SL 1.2x ATR로 확대 |
| 횡보 포지션 방치 | 6시간 time_exit | 3시간으로 축소 |
| 약한 시그널 진입 | min_score 2.0 | 2.5로 상향 |
