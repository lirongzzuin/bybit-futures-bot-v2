## v7.0 주요 변경사항

### 치명적 버그 수정
- **TP/SL 계산 버그**: 지정가 주문에서 SL이 1x ATR로 잘못 계산되던 버그 수정 → 시그널의 실제 SL 배수 적용
- **수수료 불일치**: SL 청산(서버사이드 market order)에 taker 수수료(0.055%) 정확 반영

### 리스크 관리 강화
- **레버리지 절반 축소**: 평균회귀 모드 30x → 15x (폭발 위험 제거)
- **전환 모드 레버리지**: 20x → 15x
- **최대 레버리지**: 30x → 20x
- **일일 최대 손실**: 15% → 10%
- **최대 동시 포지션**: 5 → 3
- **피라미딩 비활성화**: 소액 계좌 레버리지 폭발 방지
- **일봉 전환 보호**: KST 08:45~09:15 신규 진입 차단 + SL 타이트닝

## 전략: 시장 레짐 자동 감지

4H ADX로 시장 상태를 분류하고, 각 상태에 최적화된 전략 자동 적용:

```
ADX >= 25 → 추세장 → 추세추종 (Trend-Following)
ADX 20-25 → 전환기 → 보수적 평균회귀
ADX < 20  → 횡보장 → 평균회귀 (Mean-Reversion)
```

### 추세추종 모드 (ADX >= 25)
| 항목 | 설정 |
|------|------|
| 방향 | 4H **+DI > -DI** = 롱, 반대 = 숏 |
| 진입 | 15min EMA9/21 정배열 + MACD 확인 + RSI 40-70 |
| TP/SL | **4.0x / 2.0x ATR** (R:R 2:1) |
| 레버리지 | **15x** |

### 평균회귀 모드 (ADX < 20)
| 항목 | 설정 |
|------|------|
| 방향 | RSI < 30 = 롱, RSI > 70 = 숏 |
| 진입 | 15min RSI 극단 + BB 밴드 터치 + RSI 반전 |
| TP/SL | **1.5x / 1.0x ATR** (R:R 1.5:1) |
| 레버리지 | **15x** |

### 전환 모드 (ADX 20-25)
| 항목 | 설정 |
|------|------|
| 방향 | 4H EMA 추세 + 15min 평균회귀 |
| TP/SL | 2.0x / 1.5x ATR |
| 레버리지 | 15x |
| 특징 | 엄격한 필터 (min_score 2.5) |

## 포지션 동적 관리 — 수익 극대화 시스템

```
수익 1%+  → SL을 본전으로 이동 (손실 제로 보장)
수익 2%+  → 트레일링 SL 시작 (수익의 35% 보호)
수익 3%+  → 트레일링 강화 (수익의 50% 보호)
TP 50%   → 1차 부분 익절 (30% 청산)
수익 5%+  → 트레일링 강화 (수익의 65% 보호)
TP 80%   → TP 자동 확대 (+50%) ← 무한 반복!
수익 10%+ → 트레일링 최대 (수익의 80% 보호)
TP 200%  → 2차 부분 익절 (추가 30% 청산)
```

### 일봉 전환 보호 (KST 08:45~09:15)
- 신규 진입 차단
- 수익 중 포지션: SL을 수익의 70% 보호
- 본전 근처: 본전 SL 강제
- 손실 중: SL을 -4%로 타이트닝
