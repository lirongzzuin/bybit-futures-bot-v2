## 전략: Pullback-in-Trend v11.0

### 진입 조건 (5단계 필터)

```
1. 4H ADX >= 23         → 추세 확인
2. 4H +DI/-DI 방향      → 트렌드 방향
3. 4H EMA9 > EMA21      → 트렌드 정렬
4. 15m RSI 풀백          → 과매도/과매수
   - 롱: RSI 25-43 / 숏: RSI 57-75
5. 15m BB 밴드 근접      → 극단값
   - BB ± 0.35 ATR 이내
```
