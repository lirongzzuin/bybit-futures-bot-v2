## 핵심 전략: "상승추세에서 눌림 매수, 하락추세에서 반등 매도"

### 1. 4H 추세 판단 (상위 타임프레임)
- **EMA 9 > EMA 21** + **RSI > 45** = 상승 추세
- **EMA 9 < EMA 21** + **RSI < 55** = 하락 추세
- **ADX >= 15** = 방향성 존재

### 2. 15min 진입 조건 (하위 타임프레임)
- **롱**: 4H 상승 추세에서 15min RSI < 35 (과매도) + 하단 BB 터치 → 눌림 매수
- **숏**: 4H 하락 추세에서 15min RSI > 65 (과매수) + 상단 BB 터치 → 반등 매도
- **캔들 패턴 확인**: 해머, 장악형, 관통형/먹구름형, 대양봉/대음봉
- **RSI 반등/하락 시작 확인**: 현재 RSI vs 이전 RSI 비교

### 3. 동적 SL/TP (ATR 변동성 기반)
| ATR 백분위 | SL | TP | R:R |
|-----------|-----|-----|-----|
| 75% 이상 (고변동성) | 2.0x ATR | 1.3x ATR | 0.65:1 |
| 25~75% (보통) | 1.5x ATR | 2.0x ATR | 1.33:1 |
| 25% 미만 (저변동성) | 1.0x ATR | 0.8x ATR | 0.8:1 |

### 4. 레버리지 (ADX + 시그널 품질)
| 조건 | 레버리지 |
|------|---------|
| ADX >= 30 + 점수 3.0+ | **25x** |
| ADX >= 20 | **20x** |
| 기본 | **20x** |

### 5. 복리 성장 수학
```
거래당 실질 리스크 = 0.2% × 20x = 4%
승리 시 수익 = 4% × 1.33 (R:R) = 5.3%
패배 시 손실 = 4%

승률 55%, 200 거래/6개월:
  110 승리 × 5.3% compound + 90 패배 × 4% compound
  → 복리 효과로 기하급수적 성장
```
