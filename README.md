# Crypto Futures Auto-Trading Bot

> Bybit USDT Perpetual Futures 자동매매 시스템 — Multi-TF Scalping (15분봉 + 4H 교차검증)

거래량 상위 30개 암호화폐를 **15분마다** 모니터링하여, 4시간봉 추세 방향으로 15분봉 눌림목/반등 매매를 자동 수행하는 스캘핑 봇입니다.

## 매매 전략 (v4.2)

### 핵심 원리: "상승추세에서 눌림 매수, 하락추세에서 반등 매도"

```
4H (상위 타임프레임)          15min (진입 타임프레임)
┌─────────────────┐          ┌─────────────────┐
│ EMA 9 > EMA 21  │──확인──▶│ RSI < 35 (과매도)│
│ RSI > 45        │          │ 하단 BB 터치    │
│ ADX > 15        │          │ 반등 캔들 패턴  │
│ = 상승 추세 확인 │          │ = 눌림목 매수!   │
└─────────────────┘          └─────────────────┘
```

### 1. 4H 추세 판단
- **EMA 9 > EMA 21** + **RSI > 45** = 상승 추세
- **EMA 9 < EMA 21** + **RSI < 55** = 하락 추세
- **ADX >= 15** = 최소 방향성 확인

### 2. 15min 진입 조건 (4H 추세 방향으로만)

**롱 진입** (4H 상승 추세 시):
- RSI < 35 (15분봉 과매도 = 눌림목)
- 가격 <= 하단 볼린저 밴드 (추가 확인)
- RSI 반등 시작 (현재 RSI > 이전 RSI)
- 캔들 패턴: 해머, 상승장악형, 상승펀치

**숏 진입** (4H 하락 추세 시):
- RSI > 65 (15분봉 과매수 = 반등)
- 가격 >= 상단 볼린저 밴드
- RSI 하락 시작
- 캔들 패턴: 슈팅스타, 하락장악형, 하락펀치

### 3. TP/SL (ATR 기반)
- **SL**: 1.5x ATR(15min)
- **TP**: 2.0x ATR(15min) — R:R 1.33:1
- 동적 조정: 고변동성 시 SL 2.0 / TP 2.5, 저변동성 시 SL 1.0 / TP 1.5

### 4. 레버리지 (신호 확신도 기반)

| 조건 | 레버리지 |
|------|---------|
| ADX >= 30 + 점수 3.0+ | **15x** |
| ADX >= 20 | **10x** |
| 기본 | **5x** |

### 5. 캔들스틱 패턴 인식
- 해머 / 슈팅스타
- 상승/하락 장악형 (Engulfing)
- 관통형 / 먹구름형 (Piercing/Dark Cloud)
- 대양봉/대음봉 (Strong Momentum)
