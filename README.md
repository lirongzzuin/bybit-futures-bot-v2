## 전략: 시장 레짐 자동 감지

4H ADX(Average Directional Index)로 시장 상태를 분류하고, 각 상태에 최적화된 전략 자동 적용:

```
ADX >= 25 → 추세장 → 추세추종 (Trend-Following)
                      큰 움직임을 타고 가서 크게 수익!

ADX 20-25 → 전환기 → 보수적 평균회귀
                      엄격한 필터로 안전하게

ADX < 20  → 횡보장 → 평균회귀 (Mean-Reversion)
                      RSI 극단에서 빠르게 스캘핑!
```

### 추세추종 모드 (ADX >= 25)
| 항목 | 설정 |
|------|------|
| 방향 | 4H **+DI > -DI** = 롱, 반대 = 숏 |
| 진입 | 15min EMA9/21 정배열 + MACD 확인 + RSI 40-70 |
| TP/SL | **4.0x / 2.0x ATR** (R:R 2:1) |
| 레버리지 | **15x** |
| 특징 | 넓은 TP로 큰 추세를 끝까지 타고 감 |

### 평균회귀 모드 (ADX < 20)
| 항목 | 설정 |
|------|------|
| 방향 | RSI < 30 = 롱, RSI > 70 = 숏 (**4H 무관**) |
| 진입 | 15min RSI 극단 + BB 밴드 터치 + RSI 반전 |
| TP/SL | **1.5x / 1.0x ATR** (R:R 1.5:1) |
| 레버리지 | **25x** |
| 특징 | 타이트 SL로 높은 레버리지, 빠른 스캘핑 |

### 전환 모드 (ADX 20-25)
| 항목 | 설정 |
|------|------|
| 방향 | 4H EMA 추세 + 15min 평균회귀 |
| TP/SL | 2.0x / 1.5x ATR |
| 레버리지 | 20x |
| 특징 | 엄격한 필터 (min_score 2.5) |

```

승리 시: 3~5% × R:R(1.5~2.0) = 4.5~10% 수익
패배 시: 3~5% 손실
```
